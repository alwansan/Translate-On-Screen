## نقطة الاستئناف

- دفعة 008 أضافت خط القصص المصورة وخلفية المانغا المستقلة. نجح بناء المصدر 5a3314b في 45898119251، وأُلغيت جولة المحاكي 45898119250 عند دفع مصدر أحدث.

- دفعة 010 أضافت حزمة اليابانية إلى الإنكليزية ومنتقي أزواج محلية واختبار الاستدلال دون شبكة. طابق أحدث CI مع مصدر الدفعة قبل اعتماد الدعم. راجع `memory/sessions/010-japanese-offline.md`.
- دفعة 011 أضافت اختبار منتقي Android الحقيقي لمشاركة تطبيق واحد على API 35 وحالات SentencePiece اليابانية. نجح بناء الدفعة 011 في 45899477091 مع 70/70 JVM، منها استدلال ja→en. نجح المحاكي في 45899477061 على API 29 و35، بما يشمل اختيار تطبيق واحد على API 35. راجع `memory/sessions/011-single-app-consent.md`. تابع توسيع تغطية الترجمة المحلية ومراجعة تعليمات hm في المصفوفة. الصناديق والمحاذاة والمناطق تتطلب مشاركة الشاشة كاملة.
- دفعة 012 أضافت مهلة التفاعل وربط مظهر التلقائي وإخفاء الفقاعة على الحافة. راجع `memory/sessions/012-automatic-appearance-and-edge.md` وتحقق من أحدث CI. تابع جرد المزايا وقراءة CJK العمودي.
- نجحت الدفعة 012 في 45900383102 و45900383069 على API 29 و35. أضافت الدفعة 013 اختيار نموذج CJK عمودي واختبار ترتيب القراءة اليابانية. راجع `memory/sessions/013-vertical-ocr.md` نجح اختبار اليابانية العمودي على النظامين. فشلت الجولة الكاملة بسبب أخطاء الذاكرة على API 29 وفحص الدوران على API 35؛ نجحت المحاولة الثانية للجولة 45909525188 بـ38/38 على كل نظام.
- دفعة 014 خفّضت الفترة الافتراضية لوضع ترجمة الفيديو إلى ثانيتين وأضافت اختبار التقاط المنطقة وترجمتها دون شبكة. راجع `memory/sessions/014-subtitle-cadence.md` ونتيجة أحدث CI. جولات الجهاز لمصادر مختلفة يمكن أن تكتمل بالتوازي.
- دفعة 015 أضافت اتجاه en→ja، واختبارات التقطيع والاستدلال وقياس heap للمحاكي. تحقق من أحدث Actions واقرأ `memory/sessions/015-english-japanese.md`.

## التفويض والمراجع

المالك أجاز قرارات التنفيذ والكود وActions. اعمل على فرع التنفيذ وادفع تحديثات fast-forward مع تحقق الرأس المتوقع. فرعا hm وmain ومستودع BO للقراءة. التطبيق مستقل Apache-2.0. استخدم سلوك hm وتعليماته كمراجع وأبقِ الكود والعلامة والأصول مستقلة.

مراجع APK وXAPK و23 صورة موثقة في `memory/evidence/reference-artifacts.json` وإعادة التحقق في `memory/evidence/reference-artifact-recheck-003.json`. الصور متاحة أيضاً في hm. تجربة المالك السابقة كانت للنسخة 0.1 واختبرت الفقاعة والنافذة وOCR. فحص إعدادات OEM الفعلية غير متوفر في المحاكي، وخدمات الكاميرا والصوت تعتمد ما يثبته الهاتف. الترجمة المحلية en↔ar، واتجاه ja→en متحقق والقاموس الداخلي للمعاني إنكليزي. التحقق من 16 KiB ساكن.
