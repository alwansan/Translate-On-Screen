# رسالة استعادة مشروع ترجمة الشاشة المفتوحة

استلم مشروع `alwansan/Translate-On-Screen`، واكتب فقط على الفرع `feature/open-screen-translate`. اقرأ `AGENTS.md` ثم `memory/README.md` و`memory/PROJECT_MEMORY_AR.md` و`memory/STATE.json` والخطة `docs/PLAN_AR.md` وسجل التحقق `docs/VALIDATION.md`. تحقق من رأس الفرع وActions قبل الاستكمال؛ لا تفترض أن hash في رسالة قديمة هو الأحدث.

**الهدف:** إكمال تطبيق Android مستقل ومفتوح المصدر بديل لـTranslate On Screen 1.188، مع القراءة والترجمة والعرض فوق النص والأوضاع اليدوية/الثابتة/التلقائية والميزات المساندة. حافظ على `hm` و`main`. BLACK مثال للذاكرة للقراءة فقط؛ لا تلمسه.

**طلب المالك الأحدث:** استمر بدفعات كبيرة دون طلب تجربة هاتف بعد كل تعديل. اتخذ القرارات المعتادة ووازن التنفيذ المحلي مع GitHub Actions. حافظ على ذاكرة وخطة وملفات استعادة حديثة ومرفوعة إلى GitHub. اطلب تجربة قبول نهائية مجمعة عندما تصبح النسخة مؤهلة لها؛ لا تعلن اكتمالاً لم يُثبت.

**دليل النواة التاريخي:** نواة `0.1.0-dev` بُنيت محلياً وعلى Actions بنجاح؛ 16 JVM tests و8 اختبارات جرد وlint ناجحة. Android CI `45763162836` عند `3bca5754ed5d149b420c4af17f8243a5ef2340bd`، ثم رأس توثيق `11bca208496d8ceb1e047f3be34d5b3b434ac054` قبل الدفعة 002. المالك جرّب الفقاعة والنافذة وقراءة النص على هاتفه وأبلغ أنها عملت بلا انهيار في تجربة بسيطة. لا توسع هذا إلى جميع الأوضاع أو جودة OCR أو ترجمة فعلية.

**أدلة جديدة متاحة بالفعل:** APK وXAPK الأصليان و23 صورة. معرفات Library وروابط الصور في `memory/PROJECT_MEMORY_AR.md` وفهرس `memory/evidence/`؛ لا تطلب إعادة رفعها. مرجع الصور `hm@b4f80b12d7efafdd992d54f51ffba65c01ec6308`، والجرد الساكن القديم مثبت عند `53a10142656f60b04299fdd8fa073b0d675210ee`.

**تنبيه الاستعادة الحالي:** بيئة التنفيذ المحلية تعطلت قبل اختبار الجهاز الأخير. افحص `memory/sessions/002-environment-recovery.md` وSTATE وأحدث رأس/Actions. أُعيد تجميع مصدر0.2 في Git بعد الانقطاع؛ يلزم تحقق CI جديد لهذا المصدر، ولا تنقل نجاح النواة القديمة إليه. إذا عاد القرص القديم احفظه وقارنه دون reset. GitHub يعمل، ويمكن متابعة المصدر والبناء عبر Actions. احفظ ما يمكن استعادته قبل أي reset محلي.

**آخر بوابة مؤكدة:** نجح Actions `45771378480` عند `1741d437f67f8491fbbb298af3508496dd67f593` بعد إصلاح بناء نواة الأوضاع الخمسة. مصدر التوسعة المعاد تجميعه بعده ينتظر بواباته الخاصة؛ تحقق دائماً من STATE وActions.

**الدفعة 002 قيد التنفيذ:** تدقيق الملفين والصور، ذاكرة منظمة، أوضاع ثابتة وتلقائية وعرض صناديق النص، توسيع OCR والمزودين وفحص ترجمة محلية حقيقية، واجهة متكاملة، وتجهيز محاكي/اختبارات Android. التفاصيل الحالية في STATE وسجل الجلسة؛ لا تعتبر بنداً مكتملاً قبل ربطه بالكود والفحص.

**قيود ثابتة:** لا نسخ Smali/رسومات/مفاتيح أو backend الأصل. OCR المحلي منفصل عن الترجمة المحلية. الشبكة والسجل اختياريان، الصور لا تُحفظ، مفاتيح API مشفرة. أوقف النتائج القديمة والطلبات اللاحقة عند إلغاء الجلسة، ولا تعِد استخدام موافقة MediaProjection. محاذاة ELF 16 KiB ليست وحدها اختبار جهاز 16 KiB.

أثناء العمل احفظ checkpoints موسومة حتى إن لم يُتحقق منها بعد، كي لا تضيع الشجرة المحلية. بعد كل دفعة متحققة: ارفع الكود، انتظر بوابات CI المطلوبة، حدث STATE والخطة والمشكلات وسجل الجلسة ورسالة الاستعادة، وارفع تحديث الأدلة. افصل سجل الجلسات عن رسالة الاستعادة ليبقى هذا الملف مختصراً وقابلاً للنسخ.
