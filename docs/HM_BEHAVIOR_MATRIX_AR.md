# تتبع تعليمات الاستخدام والتفاعل في hm

مصدر الصفوف مفاتيح موارد القيم الافتراضية في شجرة hm عند b4f80b12. يصف كل مفتاح دليلاً على سلوك يراه المستخدم. هذه دفعة أولى من الجرد، تكمّل VIS-001 إلى VIS-044. أسماء الدوال والاختبارات تخص التطبيق المستقل.

| مفتاح المرجع | سلوك المستخدم | مسار التنفيذ ودليل التحقق |
| --- | --- | --- |
| tutorial_tap_drag وmove_icon | سحب من الفقاعة لترجمة مستطيل | CaptureService.showBubble؛ الاختبار الجديد bubbleDragCapturesRegionWithoutChangingFixedAreaOrPosition يفحص OCR واستبعاد النص الخارجي وثبات الموضع. |
| auto_move_detail | مهلة خمس ثوانٍ قبل تثبيت الفقاعة عند تعيين إجراء المنطقة | showBubble وcancelPendingDock؛ أضيف في الدفعة 004. اختبار assignedRegionActionDelaysBubbleDocking مضاف في 007 للتحقق من الموضع الحر ثم موضع الحافة. |
| auto_dim_detail | خفض عتامة الفقاعة بعد الخمول واستعادتها باللمس | armBubbleDim ومسار ACTION_DOWN؛ مراجعة مصدر. |
| double_tap_delay_tap | انتظار النقرة الثانية عند تعيين إجراء مزدوج | onSingleTapUp وonSingleTapConfirmed في showBubble؛ مراجعة مصدر. |
| auto_fix_transparency_detail | عرض تلقائي أوضح يغلقه لمس الشاشة | ScreenSettingsDialog وshowPositioned؛ إعداد مستقل لكل وضع، مطفأ افتراضياً. الاختبار الجديد clearerAutoOverlayConsumesDismissalThenRestoresSourceTouch يفحص استهلاك نقرة الإغلاق ووصول النقرة التالية للتطبيق. |
| auto_on_touch_detail | تسريع الترجمة التلقائية عند التفاعل | observeOutsideTouch واختبار outsideTouchExpeditesAutoAndPauseDisablesTheTrigger. |
| enable_option_single_app | مشاركة تطبيق واحد على الأنظمة الداعمة | reliableDisplay يحمي تحديد المنطقة عند تعذر مطابقة إحداثيات العرض؛ دفعة 011 تضيف اختبار منتقي Android على API 35، يختار مهمة بتطبيق منفصل ويقرأ نصها في لوحة القراءة. نجح على API 35 في 45899477061. |
| manga_background_detail | تطبيق خلفية تلقائية مستديرة بلا إطار لقراءة المانغا | زر إعدادات المانغا يفعّل خلفيات OCR الذكية، والصناديق فوق النص، ويزيل الحدود. هذه القيم تحفظ بعد الموافقة ضمن ملف MANGA. تحقق المحاكي قيد المتابعة. |
| manga_font_detail | اختيار خط قصص مصوّرة بمفتاح مستقل | مفتاح مستقل في ملف MANGA يستخدم عائلة Android casual في المعاينة والصناديق ولوحة النص. يعود إلى الخط المختار عند تعطيله. التحقق على الجهاز باقٍ. |
| keep_alive_detail وbattery_detail وautostart_detail وlockapp_detail_* | إرشادات لتشخيص اختفاء الفقاعة وإعدادات البطارية والتشغيل التلقائي والتطبيقات الأخيرة | مسار المزيد ← إذا اختفت الفقاعة العائمة، بالعربية والإنكليزية، مع رابط معلومات التطبيق النظامي. تتفاوت خيارات الشركات؛ أي جلسة جديدة تحتاج موافقة Android. تشغيل إعدادات OEM الفعلية باقٍ. |
| sub_mode_detail وmanga_mode_detail | استخدام حزم محلية للترجمة ومراجعة تغطية لغات القصص المصورة | أضيف اتجاه اليابانية إلى الإنكليزية في الدفعة 010 مع منتقي أزواج محلية. نجح استدلال الجهاز دون شبكة على API 29 و35 في 45899477061. بقية لغات hm وزمن الاستجابة للترجمة الحية باقية ضمن التدقيق. |
| auto_full_interaction_debounce | يحدد المستخدم كم ينتظر التلقائي بعد بدء اللمس | مهلة مستقلة لكل وضع من 100 إلى 1500ms. القيمة السابقة 650ms محفوظة افتراضياً. التكرار الزمني وحدود منع التداخل ثابتة. |
| text_style_settings_detail_auto_full وtext_style_settings_detail_auto_region | مظهر التلقائي يتبع الوضع اليدوي المناظر | ربط اختياري في إعدادات التلقائي الكامل والتلقائي للمنطقة. المعاينة والالتقاط يستخدمان مظهر الكامل أو المنطقة الثابتة بالترتيب. ملفات المظهر المحلية تحفظ عند التبديل. |
| icon_edge_hide | إخفاء جزء من الفقاعة عند الحافة | نسبة قابلة للتعديل للفقاعة الخاملة المستقرة عند الحافة. تبقى بقعة لمس بعرض 24dp على الأقل وتتمدد مع اللمس. اختبار العرض والاستعادة على المحاكي مضاف. |
| vertical_text_new_detail | قراءة اليابانية والصينية والكورية عمودياً | اختيار النموذج العمودي الموافق عند تفعيل تخطيط عمودي. اختبار قراءة عمود ياباني وترتيب الأحرف على Android في الدفعة 013. |
| sub_mode_detail | تحديث ترجمة النص في منطقة الفيديو | الإعداد الجديد يستخدم ثانيتين بين الدورات مع فترة قابلة للتعديل. اختبار الالتقاط يثبت ترجمة منطقة محفوظة بحزمة محلية في الجولة الكاملة واستبعاد النص الخارجي. يلزم تحقق الجهاز. |
