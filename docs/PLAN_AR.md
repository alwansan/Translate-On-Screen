## اختلافات وحدود معلنة

- الترجمة المحلية المتاحة en↔ar فقط؛ وجود 18 نموذج OCR لا يوفر ترجمة محلية لكل لغة.
- قاموس المعاني الداخلي إنكليزي؛ اللغات الأخرى تفتح روابط معاجم معلنة. قاموس الكلمات المحفوظة مستقل عنه.
- سبعة ملفات المظهر مستقلة؛ لا توجد وراثة ضمنية بين الوضع اليدوي والتلقائي.
- تحديث ما بعد التفاعل يعتمد بداية لمس خارج النافذة مع تأخير ومؤقت احتياطي؛ لا يراقب نهاية التمرير.
- مشاركة تطبيق واحد على Android 14+ تستخدم لوحة قراءة؛ المناطق والصناديق المحاذية تتطلب مشاركة الشاشة كاملة. المحتوى المحمي قد يكون فارغاً.
- الألوان الذكية تقدّر خلفية النص؛ ليست إزالة نص أو استكمال صورة.
- لا تشمل المتطلبات نسخ الإعلانات والاشتراكات وخادم المرجع وعلامته. الكود الجديد Apache-2.0، وتراخيص الاعتماديات والنماذج تبقى منفصلة.
- فحص محاذاة 16 KiB ساكن؛ لم يشغّل التطبيق على جهاز بصفحات ذاكرة 16 KiB. لم تختبر كل هواتف الشركات أو الحسابات الخارجية أو خدمات الصوت والكاميرا.
- بُنيت تطبيقات اختبار الجهاز من المصدر نفسه في وظيفة CI مستقلة؛ لم يثبت أنها نفس بايتات ملف APK الذي تبنيه وظيفة التسليم.

## ما بعد التسليم والاستئناف

الخطوة التالية الوحيدة المطلوبة من المالك هي [تجربة القبول المجمعة](ACCEPTANCE_AR.md). إذا نجحت، تحفظ طراز الهاتف وإصدار Android ونطاق الحالات المجربة، ثم يُحدّث STATE إلى القبول. إذا ظهرت مشكلة، تحفظ خطواتها وتُصلح مع اختبار مناسب، وتحدّث الحزمة والذاكرة معاً.

أصبحت بيئة Android المحلية القديمة غير متاحة أثناء العمل؛ تتوفر في الدفعة 003 بيئة Python مقيدة للمرفقات دون SDK أو محاكي؛ أُعيد بناء المصدر عبر GitHub وجرى اختباره من جديد في Actions. لا تُنقل نتائج العمل المحلي القديم إلى المصدر الحالي ولا يُدّعى تطابق بايتاته. إذا عادت البيئة القديمة تحفظ وتقارن قبل أي reset أو clean.

اقرأ [رسالة الاستعادة](../prompt/RESTORE_SESSION_AR.md) و[STATE](../memory/STATE.json) وأحدث رأس للفرع. البصمة في ACCEPTANCE_BUILD تخص حزمة المصدر المحدد، حتى لو أضيف commit لاحق للتوثيق وحده. لا تعِد تشغيل بوابات نجحت لمجرد بدء جلسة جديدة، ولا تطلب الملفات المرجعية مرة أخرى قبل استعمال معرفاتها الدائمة.
