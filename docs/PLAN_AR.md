# خطة الإكمال وحالة المشروع

آخر تحديث: 2026-11-26، بتوقيت بغداد. المستودع `alwansan/Translate-On-Screen`، فرع التنفيذ `feature/open-screen-translate`.

## الهدف وقرار الفرع

تطبيق Android مستقل ومفتوح المصدر يحقق قراءة وترجمة الشاشة والصور والنص، مع الأدوات والإعدادات التي وثقتها صور المرجع. الفرع مشتق من `hm@53a10142656f60b04299fdd8fa073b0d675210ee`؛ يبقى `hm` و`main` دون تعديل. BLACK مثال للذاكرة للقراءة فقط.

طلب المالك هو الاستمرار بدفعات وظيفية كبيرة، وإجراء الفحص المحلي أو عبر Actions، وحفظ المصدر والذاكرة باستمرار، ثم طلب تجربة قبول نهائية واحدة. لا نطلب تجارب هاتف صغيرة بعد كل إصلاح.

## الدليل المرجعي المتاح

وصل APK وXAPK و23 صورة؛ معرفاتها الدائمة في [الذاكرة](../memory/PROJECT_MEMORY_AR.md). صور GitHub مثبتة عند `b4f80b12d7efafdd992d54f51ffba65c01ec6308`، والجرد المفكك القديم عند commit مستقل. يتضمن [التدقيق الساكن](REFERENCE_AUDIT.md) أكثر من60 بنداً، ويضيف [فهرس الصور](../memory/evidence/reference-visual-requirements.json)44 شرطاً من VIS-001 إلى VIS-044.

الملفان والصور أدلة مختلفة. لا تثبت لقطة واجهة محركاً داخلياً أو جودة تشغيل. سجلات التحقق من التوقيع التي فُقدت مع بيئة التنفيذ موصوفة بحدودها في [سجل الاستعادة](../memory/evidence/reference-verification-recovery.json)، ويظل اختلاف عد DEX مسألة إعادة فحص مستقلة. لا يُستخدم أصل التطبيق أو خادمه داخل التنفيذ الجديد.

### اختلافات مقصودة وحدود معلنة

- توجد سبعة ملفات مظهر مستقلة لكل وضع؛ هذا أوسع من ثلاثة ملفات مشتركة في المرجع. لا ندّعي وراثة الأنماط بين الوضع اليدوي والتلقائي.
- زوجا الترجمة المحلية هما en↔ar فقط؛ توفر نماذج OCR أكثر لا يعني توفر ترجمة محلية لكل لغة.
- تحديث ما بعد التفاعل يعتمد بداية لمس خارج نافذتنا مع مؤقت احتياطي، ولا يرصد نهاية التمرير.
- مشاركة تطبيق واحد تستخدم اللوحة؛ لا نجمع إحداثيات غير موثوقة لرسم صناديق فوق الشاشة.
- الأصوات والكاميرا والتعرف الصوتي خدمات الجهاز؛ لا تُستبدل بواجهات مزيفة عند غيابها.
- الألوان الذكية تقدير من الصورة، وليست إزالة نص أو استكمال خلفية.
- الإعلانات والاشتراكات وخادم المرجع وعلامته التجارية ليست متطلبات نسخ.

## تسلسل البوابات المتبقية

1. **تجميع المصدر:** حفظ كل ملفات التنفيذ والاختبارات والعقود على فرع العمل. أُنجز التجميع الأساسي عند `51cc5343c90e02bbdc8f27aab89d8e16b19b019a` وأُلحقت بوابات الجهاز عند `3189a8f84d523aa1e8b853b82fb5048886c255da`. تعالج الدفعة التالية أخطاء الاختبارات وتصلح سلامة السجل والتهيئة.
2. **بوابة host:** بناء التطبيق وtest APK، اختبارات JVM والقراءة/المزودات/النماذج والترجمة native، Android lint، توقيع APK وتراخيص ومحاذاة ZIP/ELF. تحفظ النتائج من المصدر الجديد نفسه.
3. **بوابة Android:** API29/API35، موافقة حقيقية، OCR ودوران، المناطق والتلقائي والإلغاء والمؤقت، اللمس بين تطبيقين، صور وWordbook/History والواجهة وMarian دون شبكة. لا تحويل skip أو ADB exit0 إلى نجاح.
4. **مراجعة المتطلبات:** تحديث المصفوفة من رأس Git الفعلي؛ غلق النقص الوظيفي، ووصف الحدود التي يعود سببها إلى النظام أو خدمة خارجية بدقة.
5. **نسخة القبول:** APK وحجم وبصمة ومصدر وتعليمات واضحة، خطة قبول مجمعة قصيرة، ثم تجربة المالك. مفتاح إصدار الإنتاج لا يدخل Git؛ توقيع التطوير لا يُعرض كتوقيع متجر.
6. **إغلاق العمل:** إدخال نتيجة تجربة المالك ومعالجة المشكلات الفعلية إن وجدت، وتحديث ذاكرة المشروع ورسالة الاستعادة. اكتمال المصدر لا يلغي ضرورة هذه التجربة على هاتفه.

## الحفظ والاستئناف

بعد تعطل البيئة المحلية استُعيد المصدر عبر GitHub وأعيد بناؤه من ملفات وعقود معروفة. لا يوجد ادعاء تطابق بايتات مع الملفات المحلية التي تعذر الوصول إليها، ولا تنتقل نتائجها إلى المصدر المعاد. [سجل البيئة](../memory/sessions/002-environment-recovery.md) يحفظ الحدود، و[STATE](../memory/STATE.json) يحدد آخر دليل موثق.

احفظ checkpoints للمصدر أثناء العمل حتى إن كانت بوابة التحقق لم تكتمل، مع وسم واضح. بعد نجاح الدفعة حدّث SHA والاختبارات والمشكلات والخطة و[رسالة الاستعادة](../prompt/RESTORE_SESSION_AR.md). عند رجوع البيئة القديمة، احفظها وقارنها؛ لا hard reset ولا clean قبل إنقاذ ما فيها.
