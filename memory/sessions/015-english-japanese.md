# دفعة 015

أضيفت حزمة Marian اختيارية من الإنكليزية إلى اليابانية. يستخدم منتقي أزواج الترجمة فهرس الحزم نفسه، ويعرض تبديل الاتجاه بعد توفر الاتجاه المعاكس. ثُبّت مصدر الوزن والمفردات والبصمات وإسناد Apache-2.0. تحققت 23 من ملفات النماذج والتهيئة ووُلّدت 48 حالة SentencePiece مستقلة. أضيف اختبار استدلال JVM واختبار Android في وضع الطيران، وما زالت نتائج المصدر الحالي قيد التحقق.

تسجل جولة Android الجديدة حد heap الفعلي لعملية الاختبار في الملخص للتحقيق في اختلاف API 29، دون تسجيل محتوى الشاشة أو تغيير حد الذاكرة. راجع أيضاً إعادة تشغيل الدفعة 013 في 45909525188 واختبار ترجمة الفيديو في جولة 45910436541.

نجح بناء AndroidTest محلياً واجتازت حالات JVM الـ73. عبارة الكتاب تعطي «書物» في النموذج، وتزيل النتيجة فواصل المسافات المجزأة داخل الكتابة اليابانية. يتبقى تشغيل Android لهذا الاتجاه الجديد.
