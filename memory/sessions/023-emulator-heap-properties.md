# دفعة 023

تكرر حد 16 MiB على API 29 في 45912279375 عند اختبار المصدر b4a15fc. مرّت 35/43 حالة، وفشلت حالات ترجمة محلية وبعض اختبارات الملفات الكبيرة. سجّل محاكي x86_64 الإصدار 37.3.10.0 وقيمة qemu.dalvik.vm.heapsize=576m عند الإقلاع، وهما نفس القيم في الجولة التي شاهدت 576 MiB فعلياً. نجاح API 35 في الجولة نفسها 43/43 ويشمل رسم إطار المنطقة.

أضيف تسجيل dalvik.vm.heapgrowthlimit وdalvik.vm.heapsize وro.config.low_ram إلى دليل الجهاز لمقارنتها بقياس Runtime.maxMemory، دون تغيير إعدادات الذاكرة أو شروط الاختبار. تراقب جولة 45912539906 أثر محاولة OCR الإضافية وتشغيل صورة 16 KiB.
