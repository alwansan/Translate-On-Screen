# دفعة 021

أضيف خيار إظهار إطار المنطقة المحفوظة أثناء عرض نتيجة الأوضاع التي تستخدم منطقة ثابتة. يطبق لون إطار التحديد ويعمل مع الصناديق ولوحة النص. الإعداد اختياري، وتتبع المنطقة التلقائية إعداد الثابتة عند تفعيل ربط المظهر. يُزال الإطار مع طبقات النتائج قبل الالتقاط التالي. أضيف اختبار Android لرسم الإطار والتحقق من بقاء داخل المنطقة شفافاً.

نجحت الدفعة 016 للمصدر 2faf992 في 45911135845 و45911135970، ونجحت 40/40 حالة على كل من API 29 و35. سجّل التحقق حد heap مقداره 576 MiB و192 MiB بالترتيب. هذه الجولة تتحقق من سلوك التقطيع بعد تقليل التخصيصات، ولا تقيس مقدار التوفير عند حد 16 MiB.
