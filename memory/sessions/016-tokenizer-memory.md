# دفعة 016

حُصر عمر كائن JSON الوسيط لمفردات Marian في مرحلة التحميل، وأصبحت عقد شجرة SentencePiece تخصص خرائط الفروع عند الحاجة فقط. يقل تخصيص الكائنات أثناء تهيئة النموذج وتبقى قواعد الترميز وفحوص البصمات كما هي. هذه تعديلات وقائية للتحكم في ضغط الذاكرة، ويبقى تشخيص حد 16 MiB على API 29 مرتبطاً بنتائج المحاكي وإعادة تشغيل الدفعة 013.

نجح بناء AndroidTest واختبارات JVM محلياً. رُبط تشغيل بناء المضيف بالالتزام أيضاً حتى تكتمل الجولة لمصدر سابق عندما يُدفع تعديل جديد. نتائج جهاز 015 و016 تُسجّل لكل التزام بصورة مستقلة.
