## قرارات التصميم

إعادة كتابة مستقلة؛ لا ادعاء clean room صارم بعد قراءة المصدر المفكك. الكود الجديد Apache-2.0 حالياً؛ تراخيص الاعتماديات والنماذج منفصلة، وأي اعتماد GPL يستلزم توثيق أثره قبل الدمج. لا استعمال لخادم الأصل أو مفاتيحه. لا ML Kit مغلق في النواة. OCR على الجهاز، والشبكة للتـرجمة اختيارية ومعلنة؛ لا خادم سري أو افتراضي. لا حفظ لصور الشاشة، والسجل النصي opt-in، ومفاتيح API مشفرة بـAndroid Keystore.

المراحل السابقة ونتائجها، بما فيها الإخفاقات وإصلاحاتها، محفوظة في VALIDATION وملفات evidence الخاصة بكل مصدر. المصدر الحالي له أدلته المستقلة المذكورة في بداية هذه الذاكرة. تعطلت بيئة التنفيذ المحلية قبل تشغيل اختبار التطبيق على المحاكي؛ إعادة بناء المصدر والتحقق اللاحق جريا عبر GitHub وActions. إذا عادت ملفات scratch القديمة، احفظها وقارنها دون reset أو clean.
